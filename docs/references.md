# Reference notes

These references informed content choices and technology compatibility. They are not used as templates to copy.

## Public design reference

[WaslaTech](https://waslatech.tech/) presents its story, team tracks, working process, featured project and contact route in a clear narrative. Phantoms uses the general idea of a legible story and visible people/projects, while keeping its own asymmetrical editorial layout, logo, colors and visual language.

## Provided project repositories

[dashboard-phantoms](https://github.com/TheSeifDev/dashboard-phantoms) is the team's internal operations platform. Its README describes member, project, task and related internal workflows. The public assets inspected for this website contain branding marks and app/splash icons, not current-team portrait photography.

[rafiq-saas](https://github.com/TheSeifDev/rafiq-saas) describes Rafiq as an Arabic-first intelligent companion for people living with Alzheimer's and their care circle. Its project uses Next.js 16.4.6, React 19.3.0, GSAP 3.15.1 and Lenis 1.3.27; these versions informed the Phantoms site setup.

Neither repository was modified for this website.
